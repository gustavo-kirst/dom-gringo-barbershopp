# 🎯 Objetivo

Este documento tem como objetivo apresentar uma visão geral do projeto **Dom Gringo Barbershop**, descrevendo o propósito do aplicativo, o contexto em que será utilizado, os problemas que busca solucionar, seu público-alvo e os objetivos definidos para a primeira versão do sistema.

---

# 📱 Descrição do Projeto

O **Dom Gringo Barbershop** é um aplicativo mobile desenvolvido para otimizar o gerenciamento da barbearia, proporcionando uma experiência moderna, organizada e prática tanto para os clientes quanto para o administrador.

A aplicação permitirá que clientes realizem agendamentos de forma rápida, acompanhem seus planos mensais, consultem o histórico de cortes e mantenham contato direto com a barbearia.

Para o administrador, o sistema disponibilizará ferramentas para gerenciamento da agenda, controle financeiro, administração de clientes, gerenciamento de planos e acompanhamento de indicadores importantes para o funcionamento do negócio.

Todo o projeto será desenvolvido priorizando simplicidade, desempenho, organização e uma identidade visual inspirada na cultura Streetwear e Old School Barbershop.

---

# 📌 Contexto

Atualmente, grande parte dos agendamentos da Dom Gringo Barbershop é realizada manualmente através de aplicativos de mensagens, exigindo que o barbeiro consulte sua agenda, confirme horários disponíveis e organize os atendimentos manualmente.

Embora esse processo funcione para um número reduzido de clientes, ele pode se tornar mais trabalhoso conforme a demanda aumenta, dificultando o gerenciamento da agenda e o controle de informações importantes do negócio.

O projeto surge como uma solução para centralizar essas informações em um único sistema.

---

# ❗ Problema

O modelo atual apresenta algumas limitações, como:

- Agendamentos realizados manualmente.
- Maior tempo para confirmação de horários.
- Possibilidade de conflitos de agenda.
- Controle manual dos planos mensais.
- Dificuldade para visualizar indicadores do negócio.
- Dependência constante do atendimento via WhatsApp.

---

# 💡 Solução Proposta

O aplicativo Dom Gringo Barbershop oferecerá uma plataforma completa para gerenciamento da barbearia.

Entre as principais soluções estão:

- Agendamento digital.
- Consulta de horários disponíveis em tempo real.
- Gerenciamento automático dos planos mensais.
- Controle de pagamentos.
- Área exclusiva para administrador.
- Histórico completo de atendimentos.
- Organização centralizada das informações.

---

# 👥 Público-Alvo

O sistema foi desenvolvido para atender dois perfis de usuários.

## Cliente

Responsável por utilizar o aplicativo para:

- Criar uma conta.
- Realizar login.
- Agendar horários.
- Consultar seus agendamentos.
- Acompanhar o plano mensal.
- Visualizar o histórico de cortes.
- Entrar em contato com a barbearia.

---

## Administrador

Responsável pela gestão completa da barbearia.

Entre suas atribuições estão:

- Gerenciar clientes.
- Organizar horários disponíveis.
- Controlar pagamentos.
- Gerenciar planos.
- Acompanhar indicadores.
- Configurar informações do sistema.

---

# 🎯 Objetivos do Sistema

O sistema possui como principais objetivos:

- Digitalizar o processo de agendamento.
- Organizar o fluxo de atendimento.
- Melhorar a experiência do cliente.
- Reduzir tarefas administrativas.
- Centralizar informações da barbearia.
- Facilitar o controle financeiro.
- Automatizar o gerenciamento dos planos mensais.
