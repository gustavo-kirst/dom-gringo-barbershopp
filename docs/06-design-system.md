# 🎯 Objetivo

Este documento define os padrões visuais utilizados durante o desenvolvimento do aplicativo.

Seu objetivo é garantir consistência na interface, facilitar a manutenção e proporcionar uma melhor experiência ao usuário.

---

# 🎨 Identidade Visual

O aplicativo seguirá a identidade visual da Dom Gringo Barbershop, transmitindo uma aparência moderna, elegante e profissional.

Os elementos da interface deverão priorizar:

- Simplicidade;
- Boa legibilidade;
- Consistência visual;
- Facilidade de navegação.

# ✅ Feedback Visual

O sistema deverá apresentar feedback para todas as ações importantes.

Exemplos:

Sucesso

- Agendamento realizado.

Erro

- Horário indisponível.

Aviso

- Pagamento pendente.

Informação

- Solicitação enviada ao administrador.

---

# 📱 Responsividade

O aplicativo deverá adaptar corretamente seus componentes para diferentes tamanhos de tela, mantendo:

- Legibilidade;
- Espaçamento adequado;
- Alinhamento consistente.

---

# ♿ Acessibilidade

Sempre que possível, a interface deverá seguir boas práticas de acessibilidade.

Como por exemplo:

- Botões com tamanho adequado para toque;
- Contraste entre texto e fundo;
- Ícones acompanhados de texto quando necessário;
- Labels em todos os campos de formulário.

---

# 📌 Observações

Este Design System servirá como referência para todas as telas desenvolvidas durante o projeto.

Novos componentes poderão ser adicionados conforme a evolução do aplicativo, mantendo sempre a consistência visual.
